# IROA — 人機協作四維框架

**IROA** 是一套用於定義人類在 AI 協作過程中，如何從「指令者」轉變為「指揮家」的四維角色模型。它把「人類與 AI 的互動」從單純「問答」提升為「協作系統」。

## 四個角色

| 角色 | 描述 | 必備技能 |
| :--- | :--- | :--- |
| **Initiator**（意圖的建築師） | 人類主動定義意圖，AI 被動等待指令 | 洞察力、精準表達力、領域知識 |
| **Reviewer**（品質的守門人） | AI 負責生成，人類負責把關 | 批判思維、事實查核、邏輯判斷 |
| **Orchestrator**（系統的指揮家） | 人類是指揮家，整合 AI 的產出物 | 系統思維、資源管理、跨領域整合 |
| **Aligner**（靈魂的注入者） | AI 給出平均值，人類賦予靈魂 | 同理心、審美判斷、價值觀對齊 |

## 動態循環

一次協作中會在四種思維模式間反覆切換，而非線性流程：

1. **Initiator** — 定義問題的邊界
2. **Reviewer** — 確保品質的防線
3. **Orchestrator** — 系統化整合
4. **Aligner** — 賦予靈魂與價值
